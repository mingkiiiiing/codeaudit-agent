## 2. 实施记录（关键设计决策）

- **A1（C-1）**：打码在 `make_hit` 源头完成——`Rule` 基类新增类属性 `mask_snippet`（默认 False），PY/JS 两条 `HARDCODED-SECRET` 规则置 True，串行/并行/`hits_to_issues` 全路径自然覆盖，`engine.py` 零改动；脱敏用**固定长度 `********`**（等长会泄露真实长度）；仅处理命中行。**（Minor-6）** zip 物化弃用 `zf.extract` 改手工分块（1MB）写出以逐块累计实际字节，双阈值（单文件实际 > 声明、累计 > 上限）即 `IngestError`；成员名净化语义对齐 `zipfile.extract`，避免含 Windows 非法字符的正常成员从"净化成功"回归"整体失败"。**（Minor-7）** 预校验与解压两阶段统一按段 `stem.upper()` 过滤保留设备名（含 `CON.txt` 形态与目录形态），静默跳过与既有逃逸口径一致。
- **A2（M-3）**：挂死点比审查诊断的更深——Windows asyncio 的 `proc.wait()` 需等**全部管道 transport 关闭**才返回，孙进程持写端时击杀后的回收等待本身挂 ~20s；故除排空 `asyncio.wait` 兜底外，追加"击杀后先关管道（促 pending recv abort，已缓冲数据不丢）+ `proc.wait()` 5s 短兜底"，实测挂死 ~21s → ~1.5s 返回。**（M-2）** backend 配置分层：默认值 < 配置文件 < `CODEAUDIT_SANDBOX_BACKEND`（直读进程环境，与 `CODEAUDIT_DOCKER_IMAGE` 口径一致）< `--sandbox-backend`；非法值诚实降级 subprocess 并在进度事件标注。**（M-1）** `max_tool_iterations` 默认 25→12（与原硬编码一致，保持现网行为；NFR-10"最多 25 次"语义仍满足），review 两条路径改经 `_max_iterations_from_config` 消费。
- **A3（M-4）**：`TaskStore` 新增 `work_root` 可选参数 + `cleanup_workdir`（非终态拒绝、audit_id 单一安全路径段、resolve 后 parent 必须恰为 work_root——防 symlink 逃逸；失败仅 warning 不阻断删行），挂接 prune / sweep / delete 三时机；**DELETE running 任务选"只删行（行消失即协作取消信号），文件由执行体收尾 `_cleanup_if_ghost` 回收"**，避免与运行中流水线的写竞态。**（M-5）** 准入常量改惰性解析（每次调用实时读 env、缓存键含原始值），保留模块名作为测试覆写入口（None=按 env）；`_RUN_GATE` 随之惰性化。**（M-6）** 读流后、`part_path.replace(zip_path)` 之后建任务之前做第二次权威校验（与建任务间无 await），拒绝时 zip 零残留、429 与快速路径同形。
- **A4**：Roadmap 待办列表无"已交付"先例，Docker 项直接移除并在 `docs-site/roadmap.md` 已交付节新增 0.6.x 条目；其余五处按 grep 自证逐项修正。

## 5. 诚实边界与遗留

- Docker 路径（真实容器执行、`rm -f` 容器清理）仍为全 mock 单测口径，待有 Docker 环境/CI 实证（沿 W13 惯例，不虚构通过）。
- `CODEAUDIT_SANDBOX_BACKEND` 直读真实进程环境，不进 `.env` 白名单（与 `CODEAUDIT_DOCKER_IMAGE` 口径一致）。
- 终态任务目录在存活期内（未被 prune/DELETE 触发前）仍占盘——软保留设计；如需"终态即删"另行立项（涉及报告下载语义确认）。
- `docs-site/roadmap.md`「已交付」节缺 0.5.0/0.6.0 完整条目（止于 0.4.0，本次仅补 0.6.x 摘要）。
- 赛题合规矩阵 #10（Precision ≥ 85% 真跑）仍待 `GLM_API_KEY` 在线评估（`bench.real_run`）；本 Wave 全程未消耗在线 token。
- zip 目录入口（copytree 物化）不做保留设备名检查（本 Wave 范围仅 zip 入口；本机目录名无法建成 CON/ 等保留名，风险低）。
- DELETE 一个持续不吐事件的 running 任务，其文件回收要等执行体真正退出——协作式取消固有延迟，非新引入。
