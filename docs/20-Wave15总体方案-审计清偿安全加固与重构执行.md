## 4. 接口契约（并行卡共同遵守，集成人不改语义）

### 4.1 卡A 新增配置（audit/config.py AuditConfig 字段 + 分层来源）

- `api_token: str = ""`——来源 env `CODEAUDIT_API_TOKEN`；空 = 鉴权关闭（本机开发态默认，兼容既有行为）；非空时 `/api/*`（除 `GET /api/health`）要求 `Authorization: Bearer <token>` 或 `X-API-Token: <token>`，失败 401。启动时 token 为空打 WARNING 日志（无鉴权提醒）。
- `allowed_source_roots: list[str] = []`——来源 env `CODEAUDIT_SOURCE_ROOTS`（os.pathsep 分隔）；非空时 `POST /api/audits` 的 source_path 必须位于任一根之内（resolve 后 relative_to 判定），越界 400；空 = 不限制（兼容）。
- `rate_limit_per_min: int = 0`——来源 env `CODEAUDIT_RATE_LIMIT`；>0 时对写方法（POST/DELETE）按客户端 IP 滑动窗口限流，超限 429；0 = 关闭（既有测试不受扰）。
- SSE 并发上限：模块常量 `_MAX_SSE_STREAMS = 50`，超限新建 SSE 返回 429（不做排队）。

### 4.2 卡A 脱敏（LLM 路径）

- audit/detect/base.py 新增模块级 `mask_secret_text(text: str) -> str`：对单行文本做密钥形态打码（复用/对齐 W14 mask 语义，占位 `********`）；`mask_snippet` 既有语义不变。
- review.py `_issue_from_payload`：`snippet = mask_snippet(...)`（或等效套用），`evidence` 逐条过 `mask_secret_text`。
- 验收：新增 LLM 路径脱敏测试（FakeLLM 返回含密钥行区间的 payload → 断言报告 Issue 中无明文密钥）；既有 test_secret_masking.py 全绿。

### 4.3 卡B 存储契约（audit/taskstore.py）

- 连接即设 `PRAGMA busy_timeout=5000`；写操作遇 `sqlite3.OperationalError: database is locked` 指数退避重试（≤3 次）。
- `append_event` 改单事务 `BEGIN IMMEDIATE` + `INSERT ... SELECT COALESCE(MAX(seq),0)+1`（跨连接并发追加 seq 严格单调、无 PK 冲突）。
- `sweep_interrupted(grace_seconds: int = 0)` 新增参数：>0 时仅清扫 `updated_at` 早于 now-grace 的 queued/running 行（多 worker 部署设 CODEAUDIT_SWEEP_GRACE_SEC 规避兄弟 worker 复活竞态）；0 = 既有语义不变。行表需有 updated_at 维护（若无则补充，写入路径统一 touch）。
- server 侧接线归卡A（其所有权）：lifespan 改 `_get_store().sweep_interrupted(grace_seconds=_int_from_env("CODEAUDIT_SWEEP_GRACE_SEC", 0, minimum=0))`，并在 lifespan yield 后 close store（TaskStore.close 已幂等）。
- 验收：新增双连接并发压测（2 实例 × N 线程 × M 事件，断言零 OperationalError、seq 严格递增、事件零丢失）；grace 语义单测。

## 5. 验收与集成流程

1. **单卡验收**（每卡完成后立即）：集成人审查 diff（对照所有权与契约）→ 跑该卡 scoped 测试 → 卡内压力项（卡B 并发压测 / 卡A 限流与 SSE 上限测试）→ 问题当卡修复或退回。
2. **统一联调**（六卡齐后）：ruff 全仓 → pytest 全量（基线 1242 passed，零 fail 零 error）→ 前端 tsc+vitest+build → CHANGELOG [Unreleased] 追加 W15 段（集成人）→ 服务级压测（若 bench/soak 脚本可在 5 分钟内完成则跑，否则以卡A/B 压测项 + 全量回归替代并如实说明）。
3. **报备清单**（集成阶段向用户提出，批准后另起 W15.5）：models.py schema_version 校验、CallEdge 死模型清理、Rate-limit/SSE 上限是否改默认开启。
