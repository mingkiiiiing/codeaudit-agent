    代码库级智能审计与重构 Agent — 项目总览¶

    一句话定位：输入一个项目代码文件夹，Agent 自动完成「架构理解 → 问题检测 → 修复方案 → 单元测试生成 → 审计报告」全流程，像一个不知疲倦的资深代码评审员。

    1. 一页纸项目卡（可直接放简历/答辩）¶

    维度 内容
    项目名称 代码库级智能审计与重构 Agent（CodeAudit Agent）
    基座模型 GLM-5.3 Flash（OpenAI 兼容 Function Calling 接口）
    核心架构 「静态规则 + LLM Agent」双通道检测，七阶段流水线，ReAct 工具调用循环
    技术栈 Python 3.11 / FastAPI / tree-sitter（多语言 AST）/ SQLite / asyncio / Jinja2 / pytest
    三大能力 Bug 与性能检测、自动修复（Patch 生成 + 沙箱验证）、单元测试自动生成
    关键指标 问题识别精确率 ≥ 85%；千行代码审计耗时 < 30s；效率较人工初评提升 70%+
    交付形态 CLI + REST API + Web 演示界面；输出 JSON + Markdown/HTML 审计报告

    2. 简历项目描述（精简版，可直接抄）¶

    基于 GLM-5.3 Flash 构建代码库级智能审计 Agent：通过 tree-sitter 建立全库 AST 符号索引与调用关系图，采用「静态规则高召回 + LLM Agent 跨文件验证高精确」双通道架构，实现 Bug、性能、规范三类问题的自动检测（精确率 85%+）；对高危问题自动生成修复 Patch 并在沙箱中运行现有测试验证；自动生成可运行的单元测试用例（通过率筛选 + 失败重试）；千行代码端到端审计 < 30s（文件级并发 + 增量缓存），整体效率较人工初评提升 70%+。支持 Python / JavaScript / TypeScript，输出结构化审计报告（健康分 + 分级问题清单 + 修复建议）。

    4. 核心设计思想（三个"不是"，面试一句话讲清差异化）¶

    1. 不是"纯 LLM 扫代码" —— 纯 LLM 有幻觉、漏报且贵。静态规则（AST 模式 + 正则）先做零成本高召回扫描，把候选问题作为"线索"喂给 LLM 定向验证，再由 Agent 用工具追跨文件调用链确认，这就是 85% 精确率的来源。
    2. 不是"单文件审查器" —— 每个文件审查时注入符号表 + 被调函数源码切片 + 依赖图上下文，Agent 可主动调用 find_references / get_symbol 等工具跨文件取证，实现"代码库级"理解。
    3. 不是"只报告不闭环" —— 检测结果直接进入修复与验证闭环：生成 Patch → 沙箱应用 → 跑现有测试 → 生成回归单测再跑一遍，只有验证通过的修复才标记为 verified。

    5. 目录规划（实现阶段参照）¶

    codeaudit-agent/
├── audit/                    # 核心包
│   ├── ingest/               # Stage1 接入：路径/zip、语言识别、过滤
│   ├── indexer/              # Stage2 索引：tree-sitter、符号表、调用图
│   ├── understand/           # Stage3 理解：map-reduce 架构摘要
│   ├── detect/               # Stage4 检测：rules/（静态规则库）+ llm/（审查Agent）
│   ├── fix/                  # Stage5 修复：patch 生成与沙箱应用
│   ├── testgen/              # Stage6 单测生成
│   ├── report/               # Stage7 报告：JSON 聚合 + Markdown/HTML 渲染
│   ├── agent/                # Agent 运行时：循环、工具注册、预算控制（复用既有框架）
│   ├── llm/                  # GLM API 客户端：限流、重试、缓存、token 统计
│   └── sandbox/              # 沙箱执行器：subprocess、超时、资源限制
├── server/                   # FastAPI 服务（异步任务 + SSE 进度）
├── web/                      # 演示前端（上传/进度/报告查看）
├── cli.py                    # 命令行入口
├── bench/                    # Benchmark 构建与评估脚本（指标计算）
├── tests/                    # 自身单元测试
└── docs/                     # 本套文档
